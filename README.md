# RecScale

RecScale is an end-to-end collaborative filtering framework built to evaluate sparse rating network topologies and optimize user-item bias modeling at scale. Inspired by the foundational breakthroughs of the landmark Netflix Prize, this project explores the structural properties of bipartite user-movie interaction networks and implements an efficient Alternating Least-Squares (ALS) algorithm derived from Maximum Likelihood Estimation (MLE) under regularized Gaussian noise assumptions.
